## Development approach

I prefer straightforward systems over unnecessary abstraction.

I try to keep responsibilities explicit, interfaces predictable and important behavior covered by tests. When a design decision adds complexity, I want there to be a concrete reason for it.

I use modern development tools extensively during implementation, debugging and review. Speed matters, but understanding what is being shipped matters more.
